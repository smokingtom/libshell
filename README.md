# libshell - Alpha 0.1

libshell is a library made to aid in the development of my Desktop Environment. libshell was created in order to unify a few things, those being
stuff like Audio Playback, Getting Resources, Saving/Reading Settings, etc. I had previously attempted to create a sort of Desktop Environment using C++
and FLTK but it ultimately failed because I realized that it was not scalable and the code was not salvable. With libshell I hope to lay the foundation for a cleaner
and more scalable codebase.
